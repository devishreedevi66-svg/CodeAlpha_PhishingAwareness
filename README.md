# CyberSafe - Phishing Awareness Training

## About
CyberSafe is a phishing awareness training website designed to educate users about phishing attacks and online security.

## Features
- Introduction to phishing
- Types of phishing attacks
- How to identify phishing
- Real-world phishing examples
- Social engineering techniques
- Safety tips and best practices
- Interactive quiz with 10 questions and score tracking

## Technologies Used
- HTML
- CSS
- JavaScript
